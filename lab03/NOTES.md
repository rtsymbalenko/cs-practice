
## Различия команд анализа:
* git log — показывает общую ленту новостей (историю коммитов: кто, когда и зачем).
* git diff — показывает текущие изменения в коде прямо сейчас (разницу между состояниями).
* git show — открывает конкретный коммит «под микроскопом» (показывает его автора и весь его код).

## Результаты поиска:
* git log -S"def" — нашел коммит, в котором код переписали на функции (момент, когда слово "def" впервые появилось в файле).
* git blame — показал «авторство» каждой строчки калькулятора (кто конкретно написал этот кусок кода).

## Различия команд восстановления:
* git restore — сбрасывает все текущие несохраненные правки и возвращает файл к состоянию последнего коммита.
* git restore --source=... — временно вытаскивает в рабочую папку версию файла из любого старого коммита.

## Что произошло бы с правками:
* Если бы мы случайно закоммитили испорченный файл, наши старые правки (функции вычитания и умножения) стерлись бы из актуальной версии кода, и их пришлось бы вручную доставать из истории репозитория через старые коммиты. При обычном git restore незакоммиченные правки просто безвозвратно удаляются.
