Рабочая папка — это место на диске, где вы создаете и редактируете файлы проекта.  
Индекс — это виртуальный черновик, куда временно складываются выбранные файлы перед фиксацией.  
Коммит — это сохраненный в истории постоянный снимок состояния файлов из индекса с уникальным номером и комментарием.

## Различия между Git и GitHub:
* Git — это локальная программа (инструмент) на вашем компьютере для отслеживания изменений и управления историей версий кода.
* GitHub — это облачный веб-сервис (удаленный хостинг), где хранятся копии ваших Git-репозиториев для совместной работы и обмена кодом с другими.
