Рабочая папка — это место на диске, где вы создаете и редактируете файлы проекта.  
Индекс — это виртуальный черновик, куда временно складываются выбранные файлы перед фиксацией.  
Коммит — это сохраненный в истории постоянный снимок состояния файлов из индекса с уникальным номером и комментарием.

## Различия между Git и GitHub:
* Git — это локальная программа (инструмент) на вашем компьютере для отслеживания изменений и управления историей версий кода.
* GitHub — это облачный веб-сервис (удаленный хостинг), где хранятся копии ваших Git-репозиториев для совместной работы и обмена кодом с другими.

## Использованные команды:
* git status — показывает текущее состояние рабочей папки и индекса (какие файлы изменены, удалены или готовы к коммиту).
* git diff — показывает разницу между рабочей папкой и индексом (изменения, которые еще не добавлены через git add).
* git diff --staged — показывает разницу между индексом и последним коммитом (изменения, готовые к фиксации).

## Ветки:
* Ветка — это указатель на определенный коммит, позволяющий вести параллельную разработку изолированно от основного кода.
* При новом коммите ветка автоматически сдвигается вперед, указывая на самый свежий снимок истории в этой ветке.
* Слияние (merge) — это процесс объединения изменений из одной ветки в другую, собирающий параллельные линии разработки воедино.
